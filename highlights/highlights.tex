\title{Machine-Learning-Enabled Nuclear Reactor Core Design: Implementation to Single Channel Design of Molten Salt Reactor}
\end{frontmatter}
\section*{Highlights}
\begin{itemize}
       \item We proposed a ML-enabled optimization technique in designing a single channel of molten salt reactor.
       \item A reactor database was generated using the grid sampling strategy for training and Monte Carlo technique for testing.
       \item With a selected ML method, all the performance metrics were successfully predicted and classified within the 5\% relative error.
       \item We found a set of optimum solutions with specific feature parameters for each fuel-salt couple. 
       \item This method gives promising results by predicting performance metrics in a minuscule run-time with no neutron transport calculation.
\end{itemize}
